## Room Intelligence Scoring

- Towers: +2 each
- Spawns: +1.5 each
- Hostile creeps: +0.5 each
- RCL: +0.5 per level

### Difficulty (0-10)
- Towers: +2 each
- Spawns: +1.5 each
- Has walls: +2
- RCL: +1 per level

### Strategic Value (0-100)
- Sources: +20 each
- Distance: +30 (minus 5 per room away)
- Difficulty: -5 per point
- Threat: -3 per point

## Conquest Criteria

Room must meet ALL:
- ✓ Neutral OR hostile with RCL ≤ 3
- ✓ Towers ≤ 2
- ✓ Strategic value > 20
- ✓ At least 1 source
- ✓ Cooldown elapsed (1000 ticks)
- ✓ CPU bucket ≥ 1000 (only stops if critically low!)

## Room Abandonment Criteria

Room abandoned if:
- Quality score < 500
- AND we control > 2 rooms
- AND resources extracted (< 10k energy in storage)

### Quality Score Formula
```
score = (sources × 300) +
        (energy_capacity / 50) +
        (RCL × 50) -
        (distance × 100) +
        (storage_energy / 100)
```

## Speedrun Optimization

Triggers when:
- RCL < 5
- AND (storage > 50k energy OR spawn > 70% full)

Effects:
- Boost upgraders to 15
- Reduce builders by 1
- Console: `🚀 SPEEDRUN MODE`

## CPU Management (v1.3 AGGRESSIVE)

### Warning Levels
| Bucket Recovery | Status | Action |
|-----------------|--------|--------|
| ≥ 150/tick | ✅ OPTIMAL | All systems go |
| 100-149/tick | ⚠️ Below target | Warn but continue |
| < 100/tick | ⚠️ LOW recovery | Warn more but continue |
| Bucket < 1000 | 🚨 CRITICAL | Pause new military ops |

**Key Point**: The bot only stops military when bucket < 1000. Otherwise it warns you but keeps going!

### Why This Approach?
- **Aggressive Expansion**: Don't let conservative CPU limits slow you down
- **Monitor, Don't Block**: You'll see warnings but operations continue
- **Trust the System**: If recovery stays > 150/tick, you're fine
- **React to Criticals**: Only when bucket hits 1000 does the bot pause

## Troubleshooting

### "⚠️ CPU EFFICIENCY WARNING"
**Problem**: Bucket recovery < 150/tick
**Solution**: 
- Reduce scout range
- Disable military temporarily
- Reduce max controlled rooms
- Let bucket recover

### No assaults starting
**Check**:
1. RCL ≥ 4? (`room.controller.level`)
2. Bucket ≥ 1000? (`Game.cpu.bucket`) - Very low threshold!
3. Cooldown elapsed? (`Memory.strategic.militaryOperations.lastConquest`)
4. Conquerable rooms? (`Memory.strategic.roomIntelligence`)
5. Military enabled? (`ENABLE_MILITARY`)

**Note**: With v1.3 aggressive settings, bucket only needs to be above 1000 (not 8000!)

### Raiders not spawning
**Check**:
1. Assault phase = 'raid'?
2. Room cleared of hostiles?
3. Energy ≥ 600?

### Bot too aggressive (bucket dropping)
**Solutions**:
- Increase `CRITICAL_BUCKET_THRESHOLD` to 2000 or 3000 (pauses military earlier)
- Increase `CONQUEST_COOLDOWN` to 2000 (slower expansion)
- Decrease `MAX_HOSTILE_TOWERS_FOR_ASSAULT` to 1 (easier targets only)
- Set `ENABLE_MILITARY = false` (disable entirely)
- Reduce `MAX_CONTROLLED_ROOMS` to 2 (fewer rooms)

### Bot not aggressive enough
**Solutions**:
- Decrease `CRITICAL_BUCKET_THRESHOLD` to 500 (even more aggressive!)
- Decrease `CONQUEST_COOLDOWN` to 500 (faster expansion)
- Increase `AGGRESSIVE_SCOUT_RANGE` to 4 or 5 (scout further)
- Increase `MAX_HOSTILE_TOWERS_FOR_ASSAULT` to 3 (harder targets)
- Check if RCL ≥ 4 and bucket > 1000

## Best Practices

### Survival Tips
1. **Let the bot reach RCL 4** before expecting military action
2. **Keep bucket above 8000** for military operations
3. **Monitor CPU efficiency** - stay above 150 recovery/tick
4. **Watch the dashboard** - it tells you everything you need

### Expansion Strategy
1. **Scout first**: Let intelligence gather for 100+ ticks
2. **Pick targets wisely**: Low RCL, few towers, close distance
3. **Watch phases**: Don't micromanage, let the assault progress
4. **Extract resources**: Raiders bring back the spoils

### Efficiency Maintenance
1. **Abandon poor rooms**: Quality score < 500 = drop it
2. **Limit room count**: Stay at 2-3 rooms max
3. **Speedrun to RCL 5**: Faster progression = better defenses
4. **Monitor bucket**: If dropping, scale back operations

## Emergency Procedures

### CPU Crisis (bucket < 500)
**Automatic Response**: Bot pauses new military operations at bucket < 1000
**Manual Steps if bucket keeps dropping**:
1. Set `ENABLE_MILITARY = false` (disable all military)
2. Set `AGGRESSIVE_SCOUT_RANGE = 1` (minimal scouting)
3. Increase `CRITICAL_BUCKET_THRESHOLD = 5000` (more conservative)
4. Let bucket recover to 5000+
5. Re-enable military gradually
6. Monitor recovery rate - should climb back to 150+/tick

### Under Attack
1. Bot has tower defense built-in
2. Safe mode if available
3. Increase defensive rampart hits
4. Focus on survival, not expansion
5. Disable military to save CPU

### Lost Main Room
1. Bot respawns automatically
2. Will scout and rebuild
3. May take 5-10k ticks
4. Remote rooms may be lost
5. v1.3 systems recover automatically
